# sources.d · 自定义源批量入口

把**你自己有权使用**的直播订阅文件（`.m3u` / `.m3u8` / `.txt`）直接放进本目录即可，
脚本每轮会自动扫描并按频道归并进候选池，无需改 `sources.json`、订阅地址也不变。

## 支持格式

标准 M3U：

```
#EXTM3U
#EXTINF:-1 tvg-id="CCTV1.cn" group-title="大陆",中央一套
https://your-domain/cctv1/index.m3u8
#EXTVLCOPT:http-user-agent=Mozilla/5.0
#EXTVLCOPT:http-referrer=https://your-domain/
```

或 `频道名,URL` 的 TXT：

```
中央一套,https://your-domain/cctv1/index.m3u8
```

## 归并规则

- 按 `tvg-id` 归一化（忽略 `@HD` / `@SD` 等画质后缀）+ 频道名合并到同一频道。
- 同一频道的多个地址自动去重，全部作为备用候选，换源时按评分选最优。
- 每个频道最多保留 `MAX_CANDIDATES` 个（默认 20），超出时按历史成功率与延迟择优保留，当前生效地址始终保留。
- 本地源默认权重 6（高于部分公开列表），可用环境变量 `LOCAL_WEIGHT` 调整。

## 合规边界（重要）

本目录只应存放**已获合法授权或版权方主动公开**的直播源，例如你自行订阅的
运营商 IPTV、自建采集服务、官方公开流。

本项目**不会**、也请你不要用它去自动抓取全网／微信／论坛里分享的第三方转播源：
这类源绝大多数未经版权方授权，规模化聚合、保活与分发会构成侵权；微信等封闭生态
也没有合法的公开抓取接口。工具本身只维护地址列表，不提供、不托管、不缓存任何节目内容。

仅用于个人学习与家庭自建，请勿公开分发订阅地址或商用。
